## Conventions

Colours: **blue** firmware/hardware · **green** communication · **orange** cloud/backend ·
**purple** database/application · **teal** OTA · **red** errors/recovery · **grey dashed**
not implemented / not verified. Labels marked *Inferred* or *Not verified* are not
directly proven by code. Server addresses, passwords and keys are intentionally omitted.

## Re-rendering

Sources are in [`mermaid/`](mermaid) (`fn/` for function flows) with shared settings in
`mermaid/mermaid-config.json`. With the Mermaid CLI installed:

```bash
bash docs/architecture/render-diagrams.sh
```

Set `MMDC=<path to mmdc>` and `PUPPETEER_CFG=<json with executablePath>` to use a local
Chrome instead of Puppeteer's bundled one.
