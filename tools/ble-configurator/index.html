    Maintenance

    The device runs these between meter reads.

    Rebooting loses readings that are waiting for upload. Clearing the profile markers is only possible over the USB serial port.

    Meter

    Reads every value the meter offers over RS-232. A full read takes from a few seconds to a few minutes.

    If the meter refuses the saved password, "Read meter now" also tries the other passwords. Some meters lock their port after several wrong passwords.

    Device key

    Needed for network, server and password changes once the device has a key. Kept on this page only until you close it.

    The Bluetooth link is not encrypted: the key can be overheard by a receiver nearby. Use it only on site, and only when a change needs it.

    Read schedule

    Meter readings and profile reads, aligned to the meter clock. No key needed.

    Readings: 30 to 86 400 s. Profiles: minutes that divide a day, so reads land at the same times every day.

    Mobile network (APN)

    APN in use: unknown.

    Automatic picks Airtel, Jio or BSNL from the SIM and remembers what worked. IoT/M2M SIMs need their fixed APN. Takes effect at the next connection, before the next upload.

    Firmware update server

    Where the device asks for updates and registers. Change only when told to.

    The server may set its own check interval for this device. The device rejects any update the real server did not sign.

    Install a device key

    Only when automatic registration is off. Normally the device gets its key once the OTA dashboard approves it.
